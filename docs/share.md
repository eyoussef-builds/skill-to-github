# Share Skill to GitHub / شارك المهارة

[Main guide](../README.md) · [الدليل العربي](../README.ar.md)

## English

Turn a finished agent skill into a documented GitHub release: English/Arabic guides, privacy reviews, two explanatory infographics, a branded Facebook graphic and Arabic social copy. Review the publication target and say yes before publishing.

Get the free MIT-licensed skill and installation guide:
https://github.com/eyoussef-builds/skill-to-github

GitHub write access and image generation are needed for the complete workflow; agent and service costs are separate.

## العربية

حوّل مهارتك الجاهزة إلى مشروع GitHub واضح: أدلة عربية وإنجليزية، ومراجعة للخصوصية، وإنفوجرافيك بلغتين، وتصميم فيسبوك، ونصوص سوشيال عربية. راجع المستودع والرخصة ووافق قبل النشر.

المهارة مجانية بترخيص MIT، ودليل التثبيت هنا:
https://github.com/eyoussef-builds/skill-to-github

الإصدار الكامل يحتاج صلاحية كتابة على GitHub وأداة توليد صور؛ تكاليف المساعد والخدمات منفصلة.
