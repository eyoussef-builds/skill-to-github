نزّلت مشروع جديد على GitHub اسمه Skill to GitHub 🚀

كنت عايز طريقة ثابتة أحوّل بيها المهارات اللي بجهّزها مع AI إلى مشاريع يقدر غيري يفهمها ويستخدمها.
وجود الملفات لوحده مش كفاية؛ الشخص محتاج يعرف الفائدة، وإزاي يثبّت المهارة، وإيه الأدوات المطلوبة، ويبدأ بطلب واضح.

عشان كده جمّعت خطوات الإصدار والتوثيق ومواد المشاركة في مهارة قابلة لإعادة الاستخدام، لأي حد بيبني Agent Skills وعايز يشاركها.

Skill to GitHub بيعمل إيه؟
▪️ يجهّز حزمة عامة منفصلة عن الملفات والتفضيلات الخاصة
▪️ يكتب أدلة عربية وإنجليزية وتعليمات تثبيت وخطوات أول استخدام
▪️ يراجع الملفات وسجل Git قبل النشر، ثم يقرأ النسخة المنشورة للتحقق منها
▪️ يوجّه النشر بعد الموافقة على المستودع والظهور والرخصة
▪️ يجهّز إنفوجرافيك بلغتين وتصميم فيسبوك ونصوص للمنصات ورد بالرابط

من الناحية التقنية، المشروع مبني كـ SKILL.md مع مراجع وقوالب، ومعاه برنامج Python اختياري للقراءة فقط.
البرنامج يفحص قائمة ملفات محددة وأنماط بيانات حساسة وبيانات PNG، ويحسب بصمات الملفات. المساعد يكمل المراجعة البصرية ومراجعة السجل؛ فحص الأنماط وحده مش ضمان للخصوصية.

المهارة مجانية ومفتوحة المصدر بترخيص MIT، ومعاها دليل لـ 15 مساعد حسب دعمهم. الإصدار الكامل يحتاج صلاحية كتابة على GitHub وأداة توليد صور، وتكاليف المساعد والخدمات منفصلة. إعداد البوستات مش إذنًا بنشرها أو إرسال رسائل.

اكتب "ناشر المهارات" في كومنت وهبعتلك الرابط
حابب أسمع إيه أكتر خطوة بتاخد منك مجهود لما تشارك أداة أو مهارة جديدة.
