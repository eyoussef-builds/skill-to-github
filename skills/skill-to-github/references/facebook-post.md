# Facebook promo graphic for each released skill

Create one additional promotional feed-post design per skill release, alongside the English and Arabic explanatory infographics. Default to Arabic-first copy, with Latin product/technical names retained where useful. Make an English companion if requested; do not silently replace either required infographic with this design.

## Reference direction

The approved composition is the ScreenLocalizer repo announcement: an editorial brand frame around a genuine product/repository visual, with a short Arabic title and benefit, a compact feature line and one strong CTA. It introduces the tool at a glance; the infographics explain the workflow and starting steps in more detail.

Use [the brand style](brand-style.md): cream `#FAF8F2`, ink `#15130F` and yellow `#FFE04A`, with modern readable Arabic type and generous margins. A small sun cue or yellow marker underline can reinforce the brand. Target a portrait 4:5 feed image, ideally 1080×1350; verify actual exported dimensions before describing them. Use the image-generation tool and its image-editing/compositing workflow.

## Content and layout

1. An understated approved author/brand line if appropriate. Do not copy a reference's personal name unless it is approved public attribution for the current release.
2. A very large Arabic skill/product headline, optionally with a restrained yellow marker accent.
3. One short line explaining the useful result in everyday words.
4. A generous **genuine** public repo hero/product screenshot or released artifact as the central insert, with tidy rounded framing. For instruction-only skills, the actual published repo hero is suitable. Capture/read the real public source, or use a supplied real image; do not invent an app interface for a skill.
5. A compact feature or supported-platform line only when accurate.
6. One black rounded CTA panel, using yellow for the main action and cream for its short supporting line.

Keep the real screenshot/hero faithful, including original text, logos and UI colors. The surrounding frame carries the creator's yellow/cream/ink branding; an authentic product screenshot may retain different colors. Crop away browser tabs, account menus, notifications, private links/identifiers and irrelevant README text. Inspect the final insert rather than assuming generation preserved it.

Avoid turning this into a dense workflow chart, repeating the whole infographic, adding decorative robots/brains/circuits, fake devices or Facebook UI, invented claims, private screenshots, unrequested follow/purchase demands or extra contact details. Preserve supplied artwork when only a color/content correction is requested.

## CTA and comment keyword

Use the comment-to-link format from [social-post writing guidance](social-posts.md), with the same keyword as the Facebook and LinkedIn copy. Preserve an explicitly supplied keyword exactly, including Arabic spelling and spaces; do not reuse “مترجم الشاشات” for an unrelated skill. If none is supplied, choose a memorable 1–3 word Arabic name for the tool, disclose it outside the copy blocks and record it for review.

Typical CTA structure:

- Main line: `اكتب "{{الكلمة المحددة}}" في كومنت`
- Supporting line: `وهبعتلك الرابط 👇`

Prepare the requested artwork/copy without claiming automation is already active. Record the actual delivery mode: verified automation, manual delivery or setup still pending. A drafted message promise is not evidence that any comment-to-message automation exists. Keep setup gaps in private handoff notes; do not replace the required keyword CTA with a public URL in the Facebook or LinkedIn copy.

The graphic/caption task does not authorize posting, changing Meta Business Suite, creating automation, liking/responding to comments or sending private messages. Those actions need the user's separate instruction. Keep any page/business IDs, inbox links and automation configuration private.

## Deliver and review

Review the exact headline, benefit, screenshot fidelity, keyword, Arabic shaping, brand palette, CTA, dimensions and metadata. Remove private browser/account details. Save the final file durably, normally `docs/images/facebook-post-ar.png`, keep the original, and include the matching Facebook copy from the four-block social pack in the sharing bundle. Facebook and LinkedIn copy have no URLs; the exact GitHub URL belongs in SHORT and REPLY, and may appear in general bilingual infographic captions outside those platform blocks. State any unfinished delivery setup in private handoff notes rather than asserting it is live or putting operational blockers on the artwork.

A complete standard release therefore has **three separate artworks**: English infographic, Arabic infographic and Arabic-first Facebook promo design. Localize additional social-post versions when explicitly requested.
